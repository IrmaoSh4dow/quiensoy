# ¿Quién soy?

Juego romántico para Luke y Valentina. Cada quien abre la página en su dispositivo, elige su nombre y recibe una carta privada. No hay sala ni conexión entre los teléfonos.

El personaje se guarda solo en el navegador de quien lo recibió. Luke y Valentina juegan con mazos distintos, así que sus cartas no coinciden.

```bash
npm install
npm run dev
npm run test
npm run build
```

La biblioteca está en `src/data/characters.ts`.
